# MP4 Converter v2.0 사용 매뉴얼

[최신 버전 다운로드](https://github.com/MP4-Converter-Tools/MP4-GIF-Conversion-Downloads/releases/latest)

MP4를 GIF / WebP로 변환하거나 GIF / WebP 원본을 20MB 미만으로 압축하는 Windows 프로그램입니다.
파일은 PC에서 처리하며 서버에 업로드하지 않습니다.

## 1. 실행하기

1. 배포 페이지에서 Windows x64 ZIP을 다운로드합니다.
2. 이전 버전 폴더와 합치지 않고 **새 폴더에 ZIP을 전부 압축 해제**합니다.
3. `MP4-Converter.exe`를 실행합니다. Python이나 FFmpeg를 별도로 설치할 필요는 없습니다.

Windows 10/11 64비트용입니다. 실행파일 옆 폴더와 파일은 그대로 유지하세요.

## 2. MP4를 GIF / WebP로 변환하기

1. **MP4 / GIF / WebP 원본 → 찾아보기**에서 MP4를 선택합니다. 파일 한 개를 창에 끌어다 놓아도 됩니다.
2. **출력 형식**에서 **GIF** 또는 **WebP**를 고르고 저장 위치를 정합니다. 형식을 바꾸면 저장 확장자도 자동 변경됩니다.
3. **해상도 · 긴 변 (px)**와 **목표 용량**을 선택합니다. 처음에는 **800px · 20MB**로 시작하면 됩니다.
4. 필요한 경우 **고급 설정 펼치기**에서 구간과 FPS를 바꿉니다. 최초 기본 FPS는 30입니다.
5. **GIF로 변환** 또는 **WebP로 변환**을 누릅니다.
6. 최초 결과의 크기·해상도·FPS 알림을 확인하고, 이어지는 안내에 따라 저장합니다.

일부 구간만 필요할 때 시작·종료 시간을 입력합니다. 전체 영상은 **시작 `0`, 종료 빈칸**으로 두세요. 시작 시간까지 지우면 입력 오류가 납니다.

## 3. GIF를 20MB 미만으로 압축하기

1. 원본 GIF를 선택하거나 창에 끌어다 놓습니다. 작업이 **GIF 압축 (20MB)**으로 자동 변경됩니다.
2. 저장 위치를 확인합니다. 기본 결과 이름은 `원본이름_compressed.gif`입니다.
3. 기준 해상도와 FPS를 선택하고 **GIF 압축**을 누릅니다.
4. 최초 결과 알림과 필요한 경우 상향 보정 질문을 확인합니다.

GIF 압축은 **전체 재생 구간**을 사용하고, 목표 용량은 **20MB**로 고정됩니다. 원본은 덮어쓰지 않습니다.
원본 해상도를 우선 유지하고 싶다면 해상도 칸에 원본의 긴 변을 입력하세요. 기본값 800px를 사용하면 큰 원본도 먼저 긴 변 800px로 변환합니다.

## 4. WebP를 20MB 미만으로 압축하기

1. 원본 WebP를 선택하거나 창에 끌어다 놓습니다. 작업이 **WebP 압축 (20MB)**으로 자동 변경됩니다.
2. 저장 위치와 기준 해상도·FPS를 확인하고 **WebP 압축**을 누릅니다. 기본 결과 이름은 `원본이름_compressed.webp`입니다.
3. 최초 결과 알림을 확인합니다. 필요하면 압축 품질, FPS, 해상도 순서로 용량을 줄입니다.

GIF와 WebP 압축은 각각 같은 형식으로 **전체 재생 구간**을 처리하고, 목표 용량은 20MB로 고정됩니다. 원본을 덮어쓰지 않습니다. 정지 WebP와 애니메이션 WebP를 모두 읽으며, WebP의 반투명 영역도 유지합니다.

## 5. 목표 용량 선택하기

| 선택 | 동작 | 사용 예 |
| --- | --- | --- |
| **20MB** | 실제 결과를 20,000,000바이트 미만으로 맞춥니다. GIF는 FPS→해상도, WebP는 품질→FPS→해상도 순서로 줄입니다. | 용량 제한이 있는 곳에 올릴 이미지 |
| **Unlimited** | 선택한 해상도·FPS로 변환하며 용량 맞춤 재시도를 하지 않습니다. MP4→GIF / WebP에서 사용합니다. | 설정한 출력 사양을 우선하는 경우 |

Unlimited 결과도 원본 MP4보다 커질 수 있습니다. WebP는 **손실 압축 품질 100**으로 시작하며, 20MB를 넘으면 먼저 품질을 최소 35까지 조절합니다. Unlimited는 품질 100을 유지합니다. 품질 100도 무손실 압축을 뜻하지는 않습니다.
20MB 모드에서 FPS를 10까지 낮춰도 크면 해상도를 낮춥니다. 최소 크기에서도 제한을 맞추지 못하면 오류를 알리고 결과를 저장하지 않습니다.

## 6. 해상도와 FPS 설정하기

| 항목 | 설정 방법 |
| --- | --- |
| **해상도 · 긴 변** | 가로·세로 중 긴 쪽의 길이입니다. 목록에서 480·640·800·960·1280·1920·2560px를 선택하거나, **64~4096px**를 직접 입력합니다. |
| **빠른 선택** | 640px 또는 800px를 한 번에 선택합니다. 위 해상도 입력값과 연결됩니다. |
| **기준 FPS (20MB)** | 고급 설정에서 10·15·20·25·30·40·50·60 중 선택합니다. 20MB에서는 첫 변환의 기준값, Unlimited에서는 출력 FPS입니다. |
| **시작·종료 시간** | MP4에서 사용할 구간을 초 단위로 입력합니다. `1.25`처럼 소수점도 가능합니다. 종료 빈칸은 영상 끝을 뜻합니다. GIF / WebP 압축은 전체 구간을 사용합니다. |

**원본 비율을 유지하며 원본보다 해상도를 확대하지 않습니다.** 모니터 비율이 아니라 선택한 영상·GIF 파일의 비율을 따릅니다. 정수 픽셀로 맞추는 과정에서 반올림 차이는 생길 수 있습니다.

긴 변 800px를 선택했을 때의 예시는 다음과 같습니다. 원본이 충분히 크고 추가 용량 조절이 없는 경우입니다.

| 원본 비율 | 결과 해상도 예시 |
| --- | --- |
| 16:9 | 800 × 450px |
| 16:10 | 800 × 500px |
| 9:16 | 450 × 800px |
| 1:1 | 800 × 800px |

4096px는 출력 해상도 설정의 상한입니다. 원본 MP4 선택에 별도의 4096px 제한을 두지는 않습니다.

## 7. 결과 알림과 상향 보정 선택하기

**첫 번째 알림 — 설정값 렌더링 결과**

설정한 사양으로 최초 결과를 만든 뒤 **파일 크기(MB·바이트), 해상도, FPS**를 표시합니다. WebP는 압축 품질도 표시합니다. 아직 저장 전인 임시 결과입니다.

**확인 후 진행**

- **20MB 모드에서 결과가 20MB 미만·60FPS 미만:** FPS 상향 보정을 할지 묻습니다.
  - **아니요(기본 선택):** 추가 렌더링 없이 최초 결과를 저장합니다.
  - **예:** 해상도를 유지한 채 FPS를 1씩 높입니다. **처음 20MB 이상인 결과가 나오면 탐색을 멈추고**, 그때까지 확인한 20MB 미만 결과 중 용량이 가장 가까운 것을 저장합니다. 계속 제한 미만이면 최대 60FPS까지 진행합니다. 추가 시간이 들 수 있습니다.
- **20MB 모드에서 최초 결과가 20MB 이상:** 용량을 줄이는 자동 조절을 진행한 뒤 저장합니다.
- **20MB 모드에서 결과가 20MB 미만·이미 60FPS:** 상향 보정 질문 없이 저장합니다.
- **Unlimited:** 결과 확인 후 선택한 사양으로 저장합니다. 용량 조절이나 상향 보정 질문은 없습니다.

FPS에 따른 GIF 용량은 일정하게 증가하지 않을 수 있습니다. 시간을 줄이기 위해 첫 제한 도달 시 멈추므로, 전체 FPS 후보 중 최적의 용량을 보장하지는 않습니다. 실행 여부는 매 작업마다 선택합니다.

## 8. 완료·취소·다음 작업

- 완료 상태에서 **최종 해상도·FPS·용량·파일명**을 확인합니다.
- **저장 폴더 열기**로 결과를 찾을 수 있습니다.
- 작업 중 **취소**를 누르면 정리 후 멈춥니다. 실패·취소 시 원본과 기존 결과 파일을 보존합니다.
- **변환 시간**은 실제 작업 경과 시간입니다. 두 알림의 응답 대기 시간은 제외되며, 남은 시간 예측값은 아닙니다.
- 해상도·FPS·목표 용량·MP4 출력 형식은 마지막 설정을 기억합니다. GIF / WebP 압축을 사용해도 MP4의 마지막 출력 형식은 유지됩니다. 원본 파일과 구간 설정은 기억하지 않습니다.

## 9. 자주 묻는 내용

- **변환이 오래 걸려요.** 해상도·FPS·구간을 줄이면 처리량이 줄어듭니다. 필요 없는 FPS 상향 보정은 **아니요**를 선택하세요.
- **결과 해상도가 선택값보다 작아요.** 원본보다 확대하지 않으며, 20MB 모드에서는 용량을 맞추기 위해 더 낮아질 수 있습니다.
- **60FPS인데 재생이 달라 보여요.** GIF는 시간을 0.01초 단위로 기록하고 뷰어마다 처리 방식이 다릅니다. 원본 FPS보다 높여도 새로운 움직임을 생성하지는 않습니다.
- **이미 작은 GIF / WebP도 압축할 수 있나요?** 다시 변환할 수 있지만, 원본보다 더 작아진다고 보장하지는 않습니다. 재인코딩으로 색상·선명도도 달라질 수 있습니다.
- **원본 MP4는 15초·50MB 미만이어야 하나요?** 강제 제한은 없습니다. 크거나 긴 원본은 처리 시간과 메모리 사용량이 늘어날 수 있습니다.
- **GIF와 WebP 중 무엇을 고르나요?** 올릴 서비스가 애니메이션 WebP를 지원하면 색상·용량 면에서 유리할 수 있습니다. GIF만 지원하면 GIF를 사용하세요.
- **소리가 없어졌어요.** GIF / WebP에는 소리가 없으며 애니메이션 결과는 무한 반복됩니다.

버전별 변경 사항은 ZIP 안의 `CHANGELOG.md`에서 확인할 수 있습니다.
